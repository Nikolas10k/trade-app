# Monster Alto-Falantes — landing page

Página única (`index.html`) com cena WebGL (Three.js r0.160 via CDN): subwoofer procedural
que gira 360° com o scroll, faíscas, shader de ondas magenta → safira, slides com revelação
letra a letra e mídia (fotos + vídeo) em `assets/`.

Para ver: basta dar dois cliques no `index.html` (precisa de internet para o Three.js e as fontes).
